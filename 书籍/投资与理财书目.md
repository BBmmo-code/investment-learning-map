# 投资与理财书目

按主题整理投资、个人理财和财报书籍，适合结合[阅读路线](10本书阅读路线.md)选择。书中观点和历史经验需要结合市场、制度与个人情况判断。

## 个人理财

| 书名 | 作者 | 内容 |
| --- | --- | --- |
| 《小狗钱钱》 | 博多·舍费尔 | 用故事介绍储蓄、财务目标和基础财商。 |
| 《金钱心理学》 | 摩根·豪泽尔 | 从行为和案例讨论财富、风险与长期决策。 |
| 《彼得·林奇教你理财》 | 彼得·林奇等 | 从个人视角认识储蓄、投资及股票市场。 |

## 指数基金与市场

| 书名 | 作者 | 内容 |
| --- | --- | --- |
| 《漫步华尔街》（原书第 12 版） | 伯顿·G.马尔基尔 | 介绍市场历史、投资组合和指数投资。 |
| 《指数基金投资指南》 | 银行螺丝钉 | 认识指数、指数基金和估值思路。 |
| 《共同基金常识》（10 周年纪念版） | 约翰·博格 | 讨论基金投资、费用及长期收益。 |
| 《赢得输家的游戏》（原书第 6 版） | 查尔斯·埃利斯 | 讨论投资竞争、长期策略和投资成本。 |
| 《股市长线法宝》（原书第 5 版） | 杰里米·西格尔 | 以美国长期市场数据讨论股票与其他资产。 |

## 企业、财报与投资方法

| 书名 | 作者 | 内容 |
| --- | --- | --- |
| 《手把手教你读财报》 | 唐朝 | 从投资者视角理解财务报表。 |
| 《财报就像一本故事书》 | 刘顺仁 | 用较通俗的方式介绍财报。 |
| 《聪明的投资者》（第 4 版注疏点评版） | 本杰明·格雷厄姆 | 理解价值投资与安全边际。 |
| 《投资中最简单的事》（更新版） | 邱国鹭 | 讨论企业、行业与投资判断。 |
| 《投资最重要的事》（全新升级版） | 霍华德·马克斯 | 讨论风险、周期和投资思维。 |
| 《怎样选择成长股》 | 菲利普·A.费舍 | 了解成长型企业的研究视角。 |
| 《彼得·林奇的成功投资》 | 彼得·林奇等 | 介绍作者的企业研究与投资经验。 |
| 《战胜华尔街》 | 彼得·林奇等 | 通过案例了解作者的选股思路。 |
