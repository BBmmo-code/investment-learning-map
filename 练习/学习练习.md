# 学习练习：先理解，再决定

这些练习可用虚构数字或公开资料完成，不需要填写真实账户信息，也不要求购买任何产品。各项内容只用于学习，不构成投资建议。

## 1. 一个月现金流

用纸笔或本地表格记录，不要把身份证号、银行卡号、账户截图或详细财务数据提交到公开仓库。

| 项目 | 本月金额（可用虚构数字） | 备注 |
| --- | ---: | --- |
| 税后收入 | | |
| 必要支出 | | 例如住房、餐饮、交通 |
| 可调整支出 | | |
| 债务还款 | | 注明是否包含利息 |
| 剩余现金 | | 收入减去以上支出和还款 |

思考：哪些支出会每年集中出现？若收入中断或突发支出，现有可支配资金能覆盖哪些需求？高息负债的真实成本是什么？

## 2. 对比两个假想基金

先选择同一市场、相似资产类别的两个公开基金产品，以官方产品资料、招募说明书和费率公告为依据填写。**这不是购买清单**。

| 项目 | 基金 A | 基金 B |
| --- | --- | --- |
| 文件名称与日期 | | |
| 投资目标与跟踪标的 | | |
| 主要持仓或资产类别 | | |
| 管理费、托管费及其他持续费用 | | |
| 申购赎回或交易成本 | | |
| 产品文件列明的主要风险 | | |
| 如何买卖、能否随时变现 | | |

思考：名称相似是否意味着持仓相似？费率是否覆盖了所有实际成本？看起来分散的基金是否仍集中于某个行业或市场？无法确认的项目请标“待核实”。

## 3. 阅读一份公司年报

从 [巨潮资讯](https://www.cninfo.com.cn/new/snapshot/companyListCn) 或 [SEC EDGAR](https://www.sec.gov/edgar/search/) 找一份年报，记下公司、报告期、公告日期和原文链接，然后回答：

1. 公司的主要收入来自什么业务？
2. 报告中列出的主要经营或财务风险有哪些？
3. 营业收入、净利润和经营活动现金流分别是多少？它们分别说明什么？
4. 你有哪些看不懂或需要进一步核对的地方？

一份报告和几个财务指标不能单独说明公司估值是否合理。比较时注意行业、会计口径、币种和报告期。

## 4. 复利与费用情景

打开[复利计算器](https://www.investor.gov/financial-tools-calculators/calculators/compound-interest-calculator)，使用相同本金和期限，比较几种假设收益率。记录每组假设及结果；可参考[费用说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/updated?page=2)思考成本的影响。计算器使用的是确定的输入，不等于现实中收益稳定；还需要考虑波动、税费、通胀与本金损失。
