# 投资理财学习地图

一份面向普通人的投资与个人理财资源索引：从整理现金流、认识风险，到读懂基金、财报和经济数据。每条资料都说明适合谁、能学到什么、有哪些局限。

> 当前为初稿，最近整理：2026-11-05。资料用于学习，不构成个性化投资建议；历史收益和计算示例都不能保证未来结果。中国内地、美股等市场的规则和税制不同，具体事项请以当地现行规定及产品文件为准。

## 从哪里开始

不需要买书，也不需要先开证券账户。本仓库提供[可直接下载的开放教材](#仓库内可下载教材)，可按下面的顺序，完成一个阶段再进入下一个阶段：

1. **整理自己的钱**：记录一个月的收入、必要支出、负债及预留资金，认识现金流和高息负债。参考 [CFPB 财务教育资料库](https://www.consumerfinance.gov/consumer-tools/educator-tool/adult-financial-education/tools-and-resources/)；部分账户与制度介绍针对美国。
2. **认识投资风险**：阅读[投资入门](https://www.investor.gov/introduction-investing)和[资产配置与分散](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)。能解释收益不确定、分散投资不能消除损失即可。
3. **了解中国市场**：阅读[中国投资者网基金基础知识](https://www.investor.org.cn/xxzx/tzzkt/jj/)和[上交所 ETF 系列](https://edu.sse.com.cn/etfgame/gametopic/)，关注基金风险、费用和交易方式；旧文章中的具体规则应另行核验。
4. **动手看原始资料**：选择一只基金或一家上市公司，只做纸面研究：查阅正式披露文件，记录风险、费用或业务，不用真实买入。[练习模板](练习/学习练习.md)提供了具体问题。

## 如何使用这份清单

- **先看原始信息，再看观点**：对基金先看招募说明书和产品资料，对公司先看公告及财报；别只看截图、收益榜单或某位博主的结论。
- **区分事实和意见**：书籍、纪录片、股东信都有作者视角；监管机构资料侧重投教，也不能替你做适当性判断。
- **看清地区与日期**：中国内地、美国及其他市场在交易制度、税费和监管方面不同；历史课程不是现行规则手册。
- **拒绝收益承诺**：警惕高收益低风险、付费带单、转账至个人账户等说法。遇到不熟悉的产品先停下来查证。
- **用练习代替冲动操作**：[学习练习](练习/学习练习.md)提供现金流、基金比较、阅读财报与信息核验模板，所有练习均可不投入资金完成。
